Import Tips for Render Deployment
Preparing JSON Data:
  • Export Access data to JSON format
  • Validate JSON syntax before upload
  • Check required fields are populated
  • Use consistent field naming
During Import:
  • Review automatic field mappings
  • Check data preview before importing
  • Monitor validation messages
  • Import customers before cylinders
Converting Access to JSON: Use tools like Access's export feature, online converters, or scripts to convert your .mdb/.accdb files to JSON format before uploading to Varasicyl on Render.
Required Fields
Customer Data:
  • Name (required)
  • Email (required)
  • Phone (required)
  • Address (required)
  • Company (optional)
  • Notes (optional)
Cylinder Data:
  • ID (required)
  • Type (required)
  • Size (required)
  • Serial Number (optional)
  • Status (defaults to "Available")
  • Location (defaults to "Warehouse")
  • Pressure (optional)
  • Inspection dates (optional)
  • Notes (optional)
Tips for Best Results
  • Ensure your Access database is not password protected
  • Close the Access database before uploading
  • Use descriptive column names for better field mapping
  • Cylinder ID field is required - use memorable IDs like "A1", "B2", "001"
  • Serial numbers are optional for cylinders (many users don't track them)
  • Clean up data beforehand to avoid import errors
  • Backup your current data before importing
