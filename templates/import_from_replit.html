Connect to Source Database
Enter the full PostgreSQL connection URL from another Replit Varasicyl deployment. You can find this in the other Replit's environment variables under DATABASE_URL.
This will migrate ALL data types (customers, cylinders, and rental history). A backup will be created to protect your current data.
Warning: This will replace ALL data in your current database with data from the source. Make sure you have a backup if needed.
How to Get Database URL
From Another Replit:
  1. Go to the source Replit with Varasicyl
  2. Open the Secrets tab (lock icon in sidebar)
  3. Find the DATABASE_URL secret
  4. Copy the entire URL and paste it above
URL Format:
postgresql://[user]:[password]@[host]:[port]/[database]

The URL contains all connection information including host, port, username, password, and database name.
