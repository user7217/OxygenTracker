JSON Format Requirements

The JSON file should contain an array of rental history objects with these fields:

Field Description Required
customer_idCustomer IDOptional
customer_nameCustomer nameOptional
customer_noCustomer numberOptional
cylinder_idCylinder IDOptional
cylinder_custom_idCustom cylinder IDOptional
cylinder_typeCylinder typeOptional
dispatch_dateDate dispatchedOptional
return_dateDate returnedOptional
rental_daysNumber of rental daysOptional
statusRental statusOptional
Example JSON format:
[
  {
    "customer_name": "ACME Corp",
    "customer_no": "CUST001",
    "cylinder_custom_id": "A1",
    "cylinder_type": "Medical Oxygen",
    "dispatch_date": "2024-01-15T09:00:00",
    "return_date": "2024-02-15T17:00:00",
    "rental_days": 31,
    "status": "completed"
  }
]
